# Security Agent Toolkit

Python과 보안 관련 내용을 학습하면서 직접 실습한 코드와 결과물을 정리하는 저장소입니다.

현재 수업에서 배운 내용을 VS Code와 GitHub를 활용해 직접 작성하고 실행해 보면서,  
배운 내용을 복습하고 실습 과정을 기록하는 것을 목표로 하고 있습니다.

## 📌 학습 기록

이 저장소에는 수업에서 실습한 Python 코드와 관련 자료를 정리하고 있습니다.

주로 다음과 같은 내용을 학습하고 있습니다.

- Python 기초 및 문법
- 제어문과 함수
- CSV 로그 분석
- 보안 로그 구조화 및 분석
- 환경변수와 `.env`를 활용한 API 키 관리
- Git과 GitHub를 활용한 파일 관리
- LLM API 호출
- 프롬프트 엔지니어링
- JSON 응답 처리 및 파싱

수업에서 작성한 코드와 실습 결과를 중심으로 정리하고 있으며,  
아직 학습 중인 과정이기 때문에 부족한 부분이나 수정해야 할 내용도 함께 기록하고 있습니다.

## 📂 Repository 구성

```text
security-agent-toolkit/
├─ agent_core/
├─ docs/
└─ ...
```

실습 과정에서 작성한 Python 코드와 학습 자료를 주제별로 정리하고 있습니다.

특히 API를 사용하는 실습에서는 `.env`와 `.gitignore`를 활용하여  
API 키가 코드나 GitHub 저장소에 직접 노출되지 않도록 관리하는 방법도 함께 실습했습니다.

## 🔍 GitHub와 Notion을 함께 보는 방법

GitHub에서는 실제 작성한 코드와 실행 결과를 확인할 수 있고,  
Notion에서는 해당 내용을 배우면서 무엇을 익혔는지, 어떤 부분이 헷갈렸는지,  
실습 중 어떤 오류를 확인했는지를 정리해 두었습니다.

코드만 보는 것보다 학습 기록과 함께 보면  
각 실습이 어떤 내용을 배우기 위해 작성되었는지 확인하기 쉽도록 구성했습니다.

## 🚀 현재 학습 방향

현재는 Python을 중심으로 프로그래밍 기초를 익히면서  
보안 로그와 LLM API를 활용한 실습까지 범위를 넓혀가고 있습니다.

배운 내용을 단순히 강의로 끝내지 않고 직접 작성하고 실행해 보면서,  
실습 과정에서 알게 된 내용과 부족했던 부분을 계속 기록해 나가는 것을 목표로 하고 있습니다.
