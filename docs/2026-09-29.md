# 2026-09-29 (화)

## 오늘 새로 쓴 명령
- cd : 원하는 폴더로 이동 (Change Directory)
- cd .. : 한 칸 위(부모) 폴더로 이동
- cd ~ : 내 홈 디렉터리로 즉시 이동
- mkdir : 새 폴더 생성 (Make Directory)

## 찾아보고 알게 된 것
- `.`은 현재 폴더, `..`은 한 칸 위(부모) 폴더를 가리키는 상대경로다.
- 절대경로는 `/`부터 시작하는 전체 주소이고, 상대경로는 내 위치 기준이다.
- 리눅스/터미널에서는 슬래시(/)를 경로 구분자로 쓴다.

## 막힌 것
- 윈도우 탐색기에서 방금 만든 폴더(`security-agent-toolkit/docs`) 위치를 찾아 저장하는 경로가 처음엔 헷갈렸다.
