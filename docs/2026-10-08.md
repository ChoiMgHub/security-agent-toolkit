## 찾아보고 알게 된 것
처음에는 파일을 GitHub에 올리는 데 왜 여러 명령이 필요한지 헷갈렸다. 이번 과제를 진행하면서 add는 기록할 변경을 고르는 단계, commit은 선택한 변경을 내 PC에 기록하는 단계, push는 그 기록을 GitHub로 보내는 단계라는 차이를 알게 됐다. 커밋 메시지는 나중에 어떤 작업을 했는지 알아볼 수 있도록 남기는 설명이다.

untracked는 Git이 아직 추적하지 않는 새 파일이고, tracked는 Git이 추적 중인 파일이다. staged는 다음 커밋에 넣도록 변경을 선택한 상태다. git status로 현재 상태를 확인하고, git add 후에는 커밋할 내용이 제대로 선택됐는지 다시 확인해야 한다.

학습 노트는 .md 확장자의 Markdown 파일로 만들었다. 처음에는 텍스트 파일, Python 파일, Jupyter 노트북 중 무엇을 선택해야 하는지 몰랐는데, VS Code에서 새 파일 이름을 2026-10-08.md로 지정하면 된다는 것을 알게 됐다.

강사님이 순서를 정정해 주셔서 학습 노트를 먼저 작성한 뒤 실습 파일과 함께 커밋하고 푸시했다. 원래 자료에 있던 학습 노트를 한 번 더 올리는 단계는 건너뛰었다.
