## 5교시 · 기록을 보고 자동이 바꾼 것만 되돌리고, 되돌릴 수 없는 조치는 따로 표시하기

- (가) 실행한 출력 전체를 붙여 넣어 주세요. 그리고 단계 5 의 잠긴 계정과 차단한 IP 를 적어 주세요.

  - 답: 단계 5에서 잠긴 계정은 `['junho']`, 차단한 IP는 `[]`였다. 이번 자동 대응이 잠근 `dami`와 실행 중 새로 차단한 `198.51.100.90`은 해제됐고, 원래 잠겨 있던 `junho`는 유지됐다. 두 계정의 세션 종료는 각각 되돌리기 불가로 표시됐다. 처음 실행할 때는 상태가 `['junho']`, 기록이 4건으로 남아 있어 IP 해제 중 `ValueError`가 발생했다. 앞서 3교시를 다시 실행하면서 같은 상태·기록 파일이 바뀐 것이 원인이었다. 안내에 따라 4교시를 다시 실행하고 `['junho', 'dami'] 5`를 확인한 뒤 5교시를 재실행하니 아래 결과로 끝났다. 이번 롤백은 메모리의 상태를 변경하고 결과를 출력하며, 상태와 롤백 결과를 파일에 다시 저장하지 않는다.

  - 쓸 내용: ① `되돌리기 불가` 줄이 나온 이유 ② 기록하지 않고 「모두 원래대로」라고 보고할 때의 문제
  - 답: 단계 2에 `dami · 되돌리기 불가 · 세션 2개 → 세션 0개`가 표시됐다. 이미 종료한 세션은 이 실습의 롤백으로 복원할 수 없고 사용자가 다시 로그인해야 하기 때문이다. 기록은 역순으로 읽으므로 세션 종료에 대한 안내가 먼저 나오고 이어 `dami`의 계정 잠금이 해제됐다. 계정을 풀어도 이전 접속이 살아나는 것은 아니다. 세션 종료를 남기지 않고 모두 원래대로라고 보고하면 담당자와 사용자가 기존 접속까지 복구됐다고 오해해 재로그인 안내나 후속 확인을 놓칠 수 있다. `junho`도 종료된 세션은 복원되지 않으며, 기존 잠금은 유지되므로 새 로그인 가능 여부도 별도로 판단해야 한다.
